# Project 1: The Battle (Java)

An object-oriented Java console game developed in **BlueJ** where two fighters take turns attacking each other or healing, tracking health points until a victor emerges.

## Features & Progression Levels
* **D-Level:** Establishes the core `Fighter` class (managing name, health, and attack damage) and the `Battle` class to execute a basic single-turn attack sequence via `Main`.
* **C-Level:** Introduces randomized damage generation (`Random`), round tracking, turn-swapping functionality, and round update displays.
* **B-Level:** Adds healing mechanics (`healAmount`), user input parsing (`Scanner`), status reporting (`toString`), and start/end info printing.
* **A-Level:** Implements dynamic loop-driven gameplay that runs until a fighter's health points run out, alongside strict Javadoc documentation standards.

## How to Run
1. Open the project directory in **BlueJ**.
2. Right-click the `Main` class box.
3. Select `void main(String[] args)` and press **OK** to launch the game in the console window.
